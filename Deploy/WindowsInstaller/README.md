# Создание установщика для Windows

Для создания скрипта установщика был использован [Inno Setup Compiler](https://jrsoftware.org/isdl.php).

## Публикация

1. Изменить версию в константе `MyAppVersion`.

1. Если в текущей версии будет изменена версия .NET, необходимо также изменить константу `PublishDirectory`.

Установщик создается скриптом `prepare-release.ps1`. Вручную создавать его не нужно.

Создание установщика можно протестировать, нажав кнопку **Build -> Compile**. Файл будет создан в директории скрипта.
